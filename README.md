# ITC Grand Chola - Luxury Hotel Booking & Dining Platform

A full-stack luxury hotel reservation and gourmet dining web application.

## 🌟 Key Features
- **Luxury Rooms & Suites Booking**: Room browsing, availability filter, guest selection, and reservation flow.
- **Hotel Dining & Room Service**: Gourmet food menu with categorical filtering, unique culinary photography, interactive cart, and room service ordering.
- **Customer Dashboard**: Overview of room bookings and food order tracking.
- **Admin Management Portal**: Rooms, bookings, food menu items, customer orders, and reviews administration.
- **Dark Luxury Aesthetic**: Curated color palette (`#0A0E0B`, `#151C18`, `#D9A441` gold accents), responsive layout, and micro-animations.

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend**: Node.js, Express, TypeScript, TSX
- **Database & Auth**: Supabase (PostgreSQL, Authentication, Row-Level Security)
- **Payment Processing**: Integrated payment flows with Indian Rupee (₹) pricing

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Runs at: `http://localhost:5173`

### 3. Backend Setup
```bash
cd backend
npm install
npm run dev
```
Runs at: `http://localhost:3001`
